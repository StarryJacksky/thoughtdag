记录日期：2026-10-05。本文是工程计划 T10 的交付说明：文档表面里的编辑器换成 CodeMirror 6，Markdown 有排版预览；PDF、图片、HTML、Word 文档在表面里阅读；从阅读器里引用一段内容。

## 2. 编辑器是共享文档的一个视图

- 编辑器里输入的内容变成文档的一次编辑，基于这个视图最后看到的缓冲版本。
- 文档在别处的变化（另一个视图在输入、撤销、文件重新载入）应用到编辑器显示的内容上。恰好落后一步时应用同一处修改，光标随文字移动；否则按差异追上。
- 文档不接受的输入（比如只读），编辑器显示的内容退回文档的内容。
- **编辑器没有自己的撤销历史。** 撤销键问的是文档，所以撤销的是这份文档的上一步，不管是哪个视图输入的。
- 保存键触发保存，不输入任何字符。
- 按文件扩展名选择语法：Markdown、LaTeX、Python、JavaScript、TypeScript、JSON、YAML、CSS、Shell、R。Python 的缩进是四个空格。其余当纯文本。

## 3. 输入法组词

用输入法组一个中文词的过程中，编辑器里会先后出现 `n`、`ni`、`ni hao`、`你好`。

- 组词期间什么都不发给文档：半成品不是一次编辑，不进撤销历史，不写恢复稿，不触发自动保存。
- 组词结束时，它留下的内容作为一次编辑发出。撤销一步，整个词一起消失。
- 组词期间文档在别处变了：编辑器不被打扰；组词结束时，这个词落在它现在该在的位置，别处的修改保留。
- 选词用的按键（回车、空格）不会到达画布，不会发送提问，也不会触发画布的撤销。

## 4. Markdown

三种看法：文本、排版效果、两者并排。排版效果就是缓冲区渲染出来的结果，边输入边变。

渲染走的是画布上每个回答都在用的那个带净化的渲染器，没有另写一套。文件里的 `<script>`、事件属性、`javascript:` 链接会被显示或去掉，不会执行。

## 5. 阅读器

| 文件 | 怎么显示 |
| --- | --- |
| PDF | 逐页渲染，带可选中的文字层；底部显示当前页和总页数 |
| 图片 | 原图 |
| HTML | 走应用里现有的净化加沙箱视图：脚本和事件属性被去掉，沙箱不允许脚本 |
| Word（.docx） | 显示提取出来的文字，顶部写明“这是从文档里提取的文字，不是文件本身，不能在这里编辑” |

这些文件的表面里没有文档、没有编辑器、没有保存按钮。

为了能看大一些的 PDF，门上多了一个“为了显示而读”的入口，上限 64 MiB。原来那个 8 MiB 的读取仍然只用于把内容复制进节点和上下文；用新入口读到的内容只用来显示。

**打不开输入的文件。** 超过 8 MiB 的文本，或者内容不是文本的文件，表面照样打开，里面写明原因，并提供“在文件管理器中显示”。不会什么都不显示，也不会硬当文本打开。

## 6. 引用

阅读器里选中一段文字，点“引用”，画布上出现一条笔记：引用的文字，下面注明出处（PDF 是文件名和页码）。笔记不连任何线，和其他材料一样，连了线才进上下文。

笔记同时记着一条引用（`quoteRef`），指向文件的那一部分：

- PDF：文件身份加页码。
- 文本：文件身份，加上这段话本身、它前后各一小段、取自哪个版本；行号只是给人看的辅助。

单独一个行号不算引用：每次编辑行号都会变，一个仍然指向某处的行号并不能说明它指向的还是原来那段话。

目前进入上下文的是笔记里的文字。按引用去文件里重新定位、把引用冻结到某个版本，是 T11 的事。

## 8. 和计划的出入

- 计划写的是 `EditorView({documentId, surfaceId})`，实际的组件叫 `TextEditor`，多一个 `onSave`。`EditorView` 是 CodeMirror 自己的类名，同名会混。
- `ResourceReader` 的 `onQuote` 除了引用，还带上被引用的文字：PDF 的引用里只有页码，没有文字，而画布上的笔记需要文字。
- 计划说“局部拆分 MaterialReader.tsx”：拆出来的是 PDF 单页组件和库加载函数，原样移动，没有改行为。

## 9. 没做的和已知限制

- **编辑器里选中文字还不能引用。** 引用函数已经支持文本，入口只接了阅读器。
- **PDF 的引用只到页**，不带选区在页面上的位置。
- **阅读器里不能搜索、不能缩放**（PDF 按表面宽度渲染）。
- **扫描版 PDF 没有文字层**，在阅读表面里选不了字。上游的阅读浮层有“识别”功能，这里没有接。
- **历史版本和逐行冲突对比仍然没有界面。**
- **新开的表面默认出现在右侧**，会叠在已经停靠在右边的表面上。
- **只在 macOS 上验证过。**
